# Experimental work

This folder is for the unfinished lightweight direction of the project.

`LitePep-Diff` was started because the original TG-CDDPM pipeline was too expensive to train with the computational resources available to us. The idea was to test whether a smaller model could keep the text-guided peptide-generation setup while being easier to train.

The implementation reached training and preliminary generation/evaluation runs, but there was not enough time to complete a careful comparison with TG-CDDPM. For this reason, this part is kept as **experimental work**, not as a proposed or validated new method.
